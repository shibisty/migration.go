# Changelog

## Unreleased

### Changed
- The package is installed with gtr: `gtr.json` replaces `go.mod` (generated by gtr, not
  committed), and packages of the family are imported by their gtr names (`import "orm"`,
  `"orm/schema"`, `"orm-postgres"`, `"passport"`, …) instead of `github.com/shibisty/...`
  paths (ADR-0001, ADR-0002). Packages that plug into a core list it as a peer dependency.
  CI builds gtr-manager from source and runs `gtr install`.

First version: extracted from orm (`orm/migrate`) and generalized.

- `Migration[DB]`, `Store[DB]`, `Journal`, optional `Locker`: the runner knows nothing about
  a specific database.
- `Migrate`, `Rollback(steps)`, `Reset`, `Refresh`, `Status` (with `Missing`), `Pending`.
- `New` validates migrations (empty/duplicate name, missing Up).
- `Rollback` validates the whole batch before rolling anything back.
- `MemoryStore` for tests. 100% coverage.
